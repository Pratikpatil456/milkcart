# ShopSphere | E-Commerce Web Application

A Django-powered e-commerce web application designed to provide a seamless online shopping experience. Users can browse products, manage their shopping carts, place orders, and track deliveries through a simple and responsive interface.

## Overview

ShopSphere is a full-stack web application developed using Python and Django. It implements essential e-commerce functionality, including product management, user authentication, shopping cart operations, order processing, and order history.

The application also provides an administrative interface for managing products, customers, orders, and payment records.

## Key Features

- Product Catalog: Browse products with images and relevant details.
- Shopping Cart: Add and remove products and update item quantities.
- Checkout System: Submit delivery information when placing orders.
- Order Management: View previous orders and monitor their status.
- Order Tracking: Track order progress from Pending to Packed, On The Way, and Delivered.
- Wishlist: Save products for future reference.
- User Authentication: Register, log in, and log out.
- Admin Panel: Manage product listings, customer information, orders, and payment records.
- Responsive UI: Access the application through a Bootstrap-based interface.

## Technology Stack

- Backend: Python, Django
- Frontend: HTML, Bootstrap 5
- Database: SQLite
- Image Processing: Pillow
- Version Control: Git and GitHub

## Installation and Setup

1. Clone the repository:

   git clone https://github.com/Pratikpatil456/milkcart.git

2. Navigate to the project directory:

   cd milkcart

3. Install the required dependencies:

   pip install django pillow

4. Apply database migrations:

   python manage.py migrate

5. Create an administrator account:

   python manage.py createsuperuser

6. Start the development server:

   python manage.py runserver

7. Open the application in your browser:

   http://127.0.0.1:8000/
